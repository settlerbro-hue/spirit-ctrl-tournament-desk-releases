# SPIRIT/CTRL Tournament Desk · Windows Setup

[Скачать установщик Windows x64](https://github.com/settlerbro-hue/spirit-ctrl-tournament-desk-releases/releases/latest).

Desk проверяет этот канал и скачивает новую стабильную версию. Откройте «Турнирная площадка → Настройка площадки → Обновления», чтобы проверить статус и установить обновление между матчами.

В выпуске `Setup.exe` — установщик, `latest.yml` и `blockmap` нужны установленному Desk, `SHA256SUMS.txt` содержит контрольные суммы.

[Вариант Portable](https://github.com/settlerbro-hue/spirit-ctrl-tournament-desk-portable/releases/latest).

В версии 0.2.9 Desk открывается на экране LAN-сервера. Запустить и проверить CS2 по UDP можно без входа на сайт. Из приложения удалён демонстрационный режим. Организатор назначенной встречи может открыть драфт без ожидания игроков. Поддерживаются равные составы от одного до пяти игроков на команду, включая 2×2.

В версии 0.2.10 кнопка «Установить сервер» автоматически находит CS2 в Steam и устанавливает сервер, Metamod:Source, CounterStrikeSharp и MatchZy в подпапку SPIRIT-CTRL-CS2 внутри каталога игры.
